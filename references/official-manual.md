# 深圳大学算力调度平台官方手册检索导览

本文基于深圳大学算力调度平台（SZU BitaHub）官方帮助手册整理，作为功能总览与高频 FAQ 导航。**请特别区分**：
- **Core Verified**：本 Skill 核心指南覆盖的「`bita` CLI + 文件存储 + 网页开发环境配置依赖并存为镜像（及持久卷 `conda-pack` 初始化）+ 分布式训练（其他框架 / 单副本 / 单机 1–2 GPU）」均已经过真实跑通。
- **Manual Navigation Only**：以下标注「未实测」的能力仅转述自官方手册（包括 Docker 客户端推送 Harbor、`Dockerfile`/`.tar` 建镜像、多机、`H100`、超算 `Slurm`、推理等；实际界面按钮文案与示例域名以你登录后的平台控制台实时展示为准），本 Skill **未对其做过线上验证**。

> [!IMPORTANT]
> 本导览不含任何账号密码、登录令牌或 Harbor 个人凭据；所有接入命令与凭据请一律从你本人登录后页面复制。

---

## 一、平台账户与计费规则（「计费体系 / 快速入门 / 专属资源池」）

- **统一认证与团队制**：平台打通深圳大学 CAS 认证；**资源的计费与存储权限主体均为「团队」**，首次使用必须在门户加入或创建一个团队，否则无法使用文件存储与任务创建。
- **两类资源**：
  - **共享型资源（公共资源池）**：面向所有用户共享、按量计费。
  - **独占型资源（专属资源池，未实测）**：支持团队单独包日/包月包年购买节点并配置实例套餐。
- **智算 vs 超算**：平台同时包含「智算任务（容器/GPU）」与「超算任务（Slurm 调度，未实测）」。

## 二、数据、模型与代码模块地图（「文件存储 / 数据集 / 模型 / 代码管理」）

| 控制台模块 | 官方定位与功能 | 本 Skill 处理方式与备注 |
| :--- | :--- | :--- |
| **文件存储** *(已实测)* | 基于团队分配个人专属存储路径，支持页面传（推荐 `<2G`）、`bita` 命令行传（推荐 `>=2G`）和团队内共享（FAQ 二.1 明确不支持跨团队共享）。 | **主推挂载方案**；配合 Zero-Tar 代码版本目录与统一挂载点（如 `/mnt/<project>`）。 |

| **模型** *(未作为主线使用)* | 同上，将存储桶文件夹注册为模型资产并供推理部署或团队共享。 | 训练输出直接写持久卷目录即可。 |
| **代码管理（Gitea/GitHub）** *(未实测)* | 支持在平台维护 Access Token 绑定内置 Gitea 或 GitHub，提交训练任务时自动挂载到容器 `/code`。 | 官方 FAQ 二.4 注明 `gita` 镜像同步刷新频率较低且 Token 配置易出错，**官方文档自己也建议用 `bita` 上传代码到存储文件夹代替 `gita`**。 |

## 三、开发容器（「如何创建容器实例 / 创建 SSH 开发环境」；其中「存为镜像」已实测，SSH/VSCode 仅参考）

- **适用场景**：交互式调试、封装自定义镜像（「存为镜像」为主流免 Docker 路线，已验证跑通）、JupyterLab、`openssh-server` 远程登录、VNC 远程桌面（SSH/VNC 等交互连接能力本团队未做自动化接入）。
- **关键约束（来自手册与 FAQ 一.1–1.17）**：
  - **最长运行时长 24 小时**，到期自动关闭且**不自动保存容器内数据**，必须将重要文件写入持久卷挂载目录；
  - 无法在容器跑完自动关机停计费（参考 FAQ 一.3 建议：**长训练请用「分布式训练」**，训练结束自动销毁停止计费）；
  - 使用自定义镜像开开发环境时，SSH 必须装 `openssh-server`，JupyterLab 必须装 `jupyterlab`；
  - **Windows / Mac / Linux 连接限制**：计算节点不能联网，导致 VSCode `Remote-SSH` 通常无法从微软自动下载 `vscode-server`（FAQ 一.13，Windows 本地通常无缓存更难连通）；Windows CMD 不支持单引号，需按 FAQ 一.2 在 PowerShell 中执行平台给出的 SOCKS5 代理 SSH/SCP 命令（`ProxyCommand`）；私钥仅允许下载一次且 Linux/macOS 需 `chmod 600 id_rsa`；
  - **端口映射差异（FAQ 一.12）**：平台开开发环境不会像本地 `docker run` 自动触发镜像 `ENTRYPOINT`/`CMD`，镜像里的服务需手动启动；
  - **开发环境保存为镜像（FAQ 一.6）**：可在运行中的开发环境详情页点击「存为镜像」固化到自定义镜像列表。

## 四、分布式训练高级能力（「如何创建分布式训练任务 / DeepSpeed / Colossal-AI / 超参调优 / 实验管理」，多机未实测）

- **已验证能力**：`计算框架 = 其他`、`Role = worker`、`taskNum = 1`、单机 `1×` 或 `2× RTX 4090`、`envDiagnosis = 0`、`suspendDetection = 1 (30 min)`、`bita apply -f`。
- **手册记录的未实测能力（需自行参考官方详情）**：
  - **多机多卡 / 多 Role 环境变量**（「通过控制台创建 → 环境变量」）：平台自动注入 `VC_{TASK全大写}_HOSTS`、`VC_{TASK全大写}_NUM`、`VC_TASK_NAMES`、`VC_TASK_INDEX`，可配合 `torch.distributed.launch` / `torchrun`（单机最多支持选 `8` 卡套餐，多机需设 `taskNum > 1`）；
  - **DeepSpeed / Colossal-AI 框架模板**（对应官方专题章节）；
  - **超参调优 & 实验管理**（对应官方专题章节）；
  - **环境诊断（EnvDiagnosis）**：开启后任务启动前会额外占用 `5–10 分钟`（单机）或 `15–20 分钟`（多机）做健康检查；
  - **自动重试（AutoRetry）**：支持 `OnFailure`、`ExitCodeAndErrorMsg`、`Advanced`（内置了若干常见 `NCCL` / `DistBackendError` / `Gloo` 报错关键字）。

## 五、自定义镜像与 Harbor 仓库（「如何自定义构建镜像 / Harbor 镜像仓库 / 镜像迁移」）

- **实测主用路线**：在「开发环境」装好/解包环境后点「**存为镜像**」（FAQ 一.6，详见 [environment.md](./environment.md)）。
- **其他官方构建渠道（未实测，仅作导航）**：
  - 首次进「自定义镜像」开通个人镜像空间并设定 Harbor 仓库密码（与门户密码独立）；
  1. `Dockerfile`（`<= 20 MB`，**平台无法自动拉取境外镜像源**）；
  2. `仓库地址 / 客户端上传`（使用 Docker `login/tag/push` 推至 `harbor.aicloud.szu.edu.cn:5000/<用户命名空间>/<镜像名称:版本>` 后在页面同步，页面「客户端上传镜像操作指南」有详细示例）；
  3. `镜像 tar 包`（`docker save` 后经文件存储导入）；
  4. `镜像迁移`（在控制台将源自定义镜像按镜像 ID 迁移到目标仓库并查看详情地址）。

## 七、超算任务（Slurm）速查（「算力调度平台 FAQ — 四、超算使用相关FAQ」，未实测）

若使用平台「超算任务（非智算 GPU 容器）」，需采用 Slurm 脚本参数（如 `#SBATCH -J`, `-p`, `-q`, `--account`, `-N`, `--ntasks-per-node`, `--mem`, `--gres=gpu:L40S:1`），用 `sacctmgr show assoc user=$USER format=User,Account,QOS%50` 查账户与 QoS，支持 `sbatch --array` 提交阵列任务。此部分与 `bita apply` 分布式训练完全独立。
